# homebrew-pocket-paragons

I discovered a game called [Pocket Paragons](https://games.solisgamestudio.com/Pocketparagons) while on vacation and decided I wanted to make some custom cards. I couldn't find any templates that I liked online, but I did find a [PDF](https://solisgamestudio.itch.io/pocketparagonsduelset) containing the cards I already owned. After spending a LOT of time in GIMP, I had a template based on the Seris the Pyromancer set that I then used to make custom cards.

I recommend using the font [ASAP](https://fontmeme.com/fonts/asap-font/) for the text since it's either close to or exactly what's on the cards. For printing, I recommend cardstock or photo paper. Copy paper can work, but it'll warp more from the ink and won't feel as high-quality. The official cards are about 89mm tall.
